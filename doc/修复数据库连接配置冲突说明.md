# 修复数据库连接配置冲突说明

项目启动失败遇到了以下的错误信息：
```
Caused by: java.lang.RuntimeException: Driver org.postgresql.Driver claims to not accept jdbcUrl, jdbc:mysql://127.0.0.1:3306/ragent?...
```

## 报错原因分析
这是非常典型的前后配置不一致产生的问题。
在底层配置文件 `application.yaml` 中，项目配置了使用 `org.postgresql.Driver` 作为数据库驱动（因为本项目依赖了 `pgvector` 进行向量检索，所以必须使用 PostgreSQL 数据库）。但是，其底下的 `url` 栏位却错误的填写了一串 `jdbc:mysql://` 开头的 MySQL 专属连接字符串。

PostgreSQL 的驱动拒绝解析 MySQL 的链接串参数（例如 `zeroDateTimeBehavior=convertToNull` 等），所以直接抛出了异常并由于依赖注入（如 `QueryTermMappingMapper` 初始化失败）导致整个 Spring 报错关停。

## 解决与修复方案
我已经将 `bootstrap/src/main/resources/application.yaml` 中出现冲突的第 20 行：
`url: jdbc:mysql://127.0.0.1:3306/ragent?...`

**修正为了正确的本地 PostgreSQL 连接配置**：
`url: jdbc:postgresql://127.0.0.1:5432/ragent`

*(由于之前查阅过你的 docker-compose.yml 配置文件，确认本地起的一个 PostgreSQL 服务使用的就是 5432 默认端口，且库名正是 `ragent`。)*

现在你可以重新点击启动应用即可。
