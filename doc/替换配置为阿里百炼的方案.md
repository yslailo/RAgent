# 替换大模型为阿里百炼的方案说明

我们在项目底层的核心配置文件 `bootstrap/src/main/resources/application.yaml` 中进行了全面排查，发现系统其实 **已经内置了阿里百炼（bailian）的 API 支持和相关路由配置**，只需要进行简单的调整即可将其作为全局的主力模型。

## 目前存在的问题现状与分析

1. **API Key 未配置**：当前在 `application.yaml` 中引用了系统环境变量 `${BAILIAN_API_KEY:}`，需要你在系统环境或启动配置中注入此变量。
2. **对话模型（Chat）**：默认的聊天和深度思考模型已经配置为阿里百炼的 `qwen3-max`：
   ```yaml
   chat:
     default-model: qwen3-max
     deep-thinking-model: qwen3-max
   ```
3. **向量模型（Embedding）**：这是需要修改的主要地方。目前系统默认使用的 Embedding 模型是指向 `siliconflow`（硅基流动）的 `qwen-emb-8b`，如果你想全盘替换为阿里百炼，需要在此处新增阿里百炼的 Embedding 候选并将其设为默认。

---

## 具体需要修改的位置及方案

### 第一步：设置百炼环境 API Key
有两种方式注入你的阿里百炼 API Key：
1. **环境变量**：在你的运行环境（例如 Docker 的 `docker-compose.yml` 或者 IDEA 的启动配置）中配置环境变量 `BAILIAN_API_KEY=你的真实Key`。
2. **硬编码（不推荐）**：直接在 `bootstrap/src/main/resources/application.yaml` 约 109 行直接替换为 `api-key: "你的真实Key"`。

### 第二步：增加百炼的 Embedding 模型配置
在 `bootstrap/src/main/resources/application.yaml` 文件中的 `ai.embedding` 区域（约 150 行）进行以下修改：

**修改前**：
```yaml
  embedding:
    default-model: qwen-emb-8b
    candidates:
      - id: qwen-emb-8b
        provider: siliconflow
        model: Qwen/Qwen3-Embedding-8B
        dimension: ${rag.default.dimension}
        priority: 1
      # ...其他本地配置
```

**修改后（新增 bailian 模型的 candidate 并设置为默认）**：
```yaml
  embedding:
    default-model: text-embedding-v3 # 修改默认模型为百炼的
    candidates:
      - id: text-embedding-v3
        provider: bailian
        model: text-embedding-v3
        dimension: ${rag.default.dimension}
        priority: 1
      - id: qwen-emb-8b
        provider: siliconflow
        model: Qwen/Qwen3-Embedding-8B
        dimension: ${rag.default.dimension}
        priority: 2
      # ...保持原有的 local 配置
```

## 实施结果 (已完成)

我已经帮你自动修改了 `bootstrap/src/main/resources/application.yaml` 文件，将系统全局的 Chat、DeepThinking 和 Embedding 模型配置全部切换为使用阿里百炼。

**你需要做的最后一步**：
你在本地运行项目时，不需要修改任何代码了，只需要显式地提供你的 API Key。

**如果你是在 IDEA 中运行（推荐）：**
1. 点击顶部菜单栏的启动配置按钮，选择 `Edit Configurations...`。
2. 找到本项目的 Spring Boot 启动类配置（或 Application 配置）。
3. 找到 `Environment variables` 配置项。
4. 在输入框中填入：`BAILIAN_API_KEY=sk-xxxxxxxxxxxxxxxxxxx` (将其替换为你真实的百炼 API Key)。
5. 点击 Apply 保存后启动即可。

**如果你通过 docker-compose 运行应用容器：**
在服务容器的 `environment:` 节点下加上 `BAILIAN_API_KEY: "sk-xxxxxxxxxxxxxxxxxxx"` 即可。
