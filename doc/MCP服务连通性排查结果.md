# MCP Server 无法连接排查结论

由于主程序报出 `Failed to connect to localhost/[0:0:0:0:0:0:0:1]:9099` 错误，我们对系统在跑的端口进行了排查分析。

## 排查过程与结果
我们在后台执行了检测命令 `netstat -ano | findstr :9099`，结果显示**当前你的操作系统中没有任何一个进程在监听 9099 端口**。

## 结论
这说明了你虽然尝试启动了 `F:\java_idea\ragent\mcp-server`，但是该服务**并没有真正在后台保持存活和正在运行**，或者它遇到了某个致命错误在启动的一瞬间就直接退出了。这也是导致主程序连不上它的直接且唯一原因（服务根本不在）。

## 下一步建议
请你查看一下运行 `mcp-server` 的那个控制台或 IDEA 运行窗口中的最新日志输出。里面一定有它报错退出的具体原因（譬如缺少某些配置、依赖冲突等）。你可以把它的报错日志发过来，我继续帮你看看。
