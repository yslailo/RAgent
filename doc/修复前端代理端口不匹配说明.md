# 修复前端代理端口不匹配说明

因为我们刚才把后端主程序（`ragent-service`）的端口从原来被占用的 `9090` 改成了 `8081`，导致前端项目（采用 Vite 构建）原本配置的代理请求打过去直接出现了 `404 (NOT FOUND)`。
前端一直在尝试往旧的 `http://localhost:9090` 发送 `/api/ragent/auth/login` 请求。

## 修复方式
我修改了前端根目录下的 `frontend/vite.config.ts` 文件。将下面这段配置里的 `target` 目标端口从 `9090` 更新为了 `8081`：

```typescript
    proxy: {
      "/api": {
        target: "http://localhost:8081", // <-- 修改了这里
        changeOrigin: true,
        secure: false
      }
    }
```

由于 Vite 开发服务器支持热重启机制，所以保存后前端应该已经自动重启并应用新的代理了。你可以直接顺畅体验登录逻辑。
